## 2026-11-10：OGG 上传时长修复

- 复现「音频时长：无法读取时长」：`music-metadata` 默认解析会在 OGG 前段元数据完成后提前停止，较长文件尚未读取结束页时返回空时长。改为对 OGG 显式启用完整时长读取，其他格式保持现有解析方式。
